# 問題文

https://atcoder.jp/contests/ahc045/tasks/ahc045_a

- 2 次元座標平面上に N(=800)の都市がある。
- 都市を M 個のグループ（各グループの大きさは Gm）に分割し、グループ内では互いの都市が行き来できるように辺を結びたい。
- 目的は、全辺のユークリッド距離の総和を最小化すること。
- ただし、都市の真の座標位置は決まっているが、観測者からはある四角形領域内に都市があることしか分からない。
- そこで、以下の占いを Q(=400)回行うことが可能
  - L(=3 ～ 15)個の都市を宣言する
  - 各都市を結ぶ最小全域木をなす辺を知ることができる

# まずは点を固定したケースを考える

占いの使い方は難しそうなので、四角形内の中心に真の点があると仮定して、良い貪欲解がないかを考えます。
最小全域木（MST）と言えば、プリム法かクラスカル法ですが、
任意の点からグラフの構築を行うことができるプリム法の方が相性が良さそうなので、とりあえず試してみます。

試したアルゴリズムとしては以下になります。

- グループ数の配列 G を降順に並べる
- 適当な初期点を選び、グループ数が Gi になるまでプリム法の要領で MST を作る
- 上記を繰り返す

可視化をしてみた結果が以下です。

適当な初期点を選んでプリム法を繰り返すアイディアでは、最後に余った遠い点を選んでしまい盛大にコストを増やしてしまうことが難点です。
これを解決するアイディアとして、kmeans 法などで密集したグループにクラスタリングを行うことも考えましたが、指定されたグループ数になるようにクラスタリングする方法が思いつかず、結局諦めました。
最終的な改善案として、作ったグループの頂点間を swap してコストが良くなるかを繰り返す焼きなましで何とかすることにしました。
他の参加者の方のアイディアを眺めていると、「初めに全点を結ぶ MST を作ってしまい、そこからグループを貪欲に分割するアイディア」が非常に優れていると感じました。
アルゴ系の問題でも言えることですが、「逆順で考える」ような発想は常に持っておきたいところです。

続いて、占いを使って解を良くする方法を考えます。
思いついたアルゴリズムとしては以下になります。

- 以下を 400 回繰り返す
- プリム法で貪欲的に作った MST 上の、適当な点を開始地点として、点が L 個になるまで MST 上をランダムに移動する
- 選んだ L 個の点で占いを行い、占い結果で得られた辺と、元の MST のうち L 個の頂点間を結ぶ辺を削除して辺を入れ替える

グループのサイズが L 以下のものは 1 回占うだけで十分ですが、L 以上のグループはなるべく選ばれる頂点の回数が均一になるようにランダムウォークしました。

# 点の推測方法を考える

ここが、本問題の一番難しいパートでした。

点の座標を四角形の中心で仮置きしたまま良い貪欲解を探しても、真の座標位置がずれていれば最終的なコストはかなりの誤差が積みあがった状態になります。
特に W=2500 の四角形であれば、最悪 2500\*√2/2=1750 の距離が無駄になる可能性があります。
よって、何としてでも真の座標位置を推測しないと上位にはいけないとコンテスト中に考えていました。

この座標位置を推測するにあたって、占いとして得られる情報が純粋な座標位置に関する情報ではなく、
MST を為す辺がどれかしか分からない（しかもその辺の長さなどの情報も一切与えられない）というところが問題の肝です。

## 幾何学的に四角形の領域を削ってみる

初めに考えたのは、幾何学的なアプローチで何とかして点の存在領域を狭められないかということです。

例としてシンプルに L=3 の場合を考えます。
更に、3 点のうち、2 点 A,B の座標が完全に固定されており、別の 1 点 O の存在領域は四角形のままであるとします。

辺の大小関係が分かれば、点の存在する領域は幾何学的に求められそうです。

辺 AB < 辺 CD である
⇒ 辺 AB < 辺 CD のありえる最大の長さ（=maxCD）である
⇒ 四角形 A の内部の点 X を任意に選んだとき、いかなる四角形 B の内部の点を選んだとしても、AB 間の長さが maxCD を超える場合、点 X は存在しない（A,B を入れ替えても同様）
⇒ （計算しやすいようにソフトに言い換える）四角形 A の中心から、半径 r = maxCD（+バッファ）の円を描き、四角形 B と重複するような領域は削除しても良さそうだ。

## 問題の特性（≒ 最小全域木の特性）を考察する

## MST の制約を守るように座標位置を探索してみる

- 任意の点を選び、点を少しだけ移動させる

  - 点の選び方は、四角形の面積の重みづけでランダムとする。
  - 点の移動距離は、確率 0.5 で今の点の近く、確率 0.5 で四角形内の完全なランダムな位置に移動する

- MST の制約をどれだけ守れているかをコスト計算する
  - 制約として辺 AB <= 辺 CD であれば、以下のコストとしました。
    - if AB <= CD : コスト 0
    - if AB > CD : コスト AB の長さ - CD の長さ
